E-Mail-Signaturen

Die fertigen CASA-Signaturen für alle Personen und Funktionspostfächer. Eigene Signatur suchen, auf „Signatur kopieren“ klicken und in Outlook einfügen. Mit „Bearbeiten“ lassen sich Name, Funktion oder E-Mail-Adresse vorher anpassen.

Outlook für Windows (klassisch)
  1. Datei → Optionen → E-Mail → Signaturen
  2. Neu → Namen eingeben
  3. Ins Bearbeitungsfeld klicken, Strg+V
  4. Rechts als Standard für neue Nachrichten und Antworten wählen → OK
Neues Outlook / Outlook im Web
  1. Zahnrad → Konten → Signaturen
  2. Neue Signatur → Namen eingeben
  3. Ins Feld klicken, Strg+V (Mac: Cmd+V)
  4. Standard für neue Nachrichten und Antworten wählen → Speichern
Outlook für Mac
  1. Outlook → Einstellungen → Signaturen
  2. „+“ → Namen eingeben
  3. Ins Feld klicken, Cmd+V
  4. Standard-Signatur für das Konto festlegen

Funktionspostfächer (info@, abend@ …): in Outlook das Postfach als Konto auswählen und die Signatur für dieses Konto als Standard setzen.
